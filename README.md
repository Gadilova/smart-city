# 🏙️ Smart City Dashboard

Веб-панель мониторинга «умного города» (Алматы). Backend на Python (FastAPI) собирает показания датчиков, хранит их в SQLite и отдаёт через свой API, а дашборд в браузере каждые 3 секунды берёт с него свежие данные.

Погода и качество воздуха — настоящие, из бесплатного API [Open-Meteo](https://open-meteo.com/). Трафик, парковки и освещение пока симулируются случайными числами на сервере.

## Модули
- 🚦 Трафик: машин в минуту, предупреждение о пробках
- 🌫️ Качество воздуха: индекс AQI и PM2.5 (Open-Meteo)
- 🌡️ Погода: температура, влажность, ветер (Open-Meteo)
- 🅿️ Парковки: свободные места
- 💡 Освещение: автоматический ночной и дневной режим
- 🗺️ Карта датчиков (Leaflet) и 📈 график истории (Chart.js)

## Как запустить

### Backend (Python + FastAPI)
Нужен Python 3.9 или новее.

```bash
cd backend
python3 -m venv .venv                     # создать виртуальное окружение (один раз)
.venv/bin/pip install -r requirements.txt # установить библиотеки (один раз)
.venv/bin/uvicorn main:app --reload       # запустить сервер
```

Потом открой:
- http://localhost:8000 — дашборд
- http://localhost:8000/docs — документация API, где можно отправить запросы прямо из браузера

Остановить сервер: `Ctrl+C` в терминале.

Дашборд работает только вместе с backend: если открыть `index.html` напрямую или через Live Server, данных не будет.

## API
| Адрес | Что возвращает |
|-------|----------------|
| `GET /api/city` | Сводка по городу для карточек и погода |
| `GET /api/sensors` | Все датчики на карте с последними показаниями |
| `GET /api/history?limit=20` | История сводок для графика |

## Структура
| Файл | Что делает |
|------|-----------|
| `frontend/index.html` | Разметка страницы: карточки, карта, график, журнал |
| `frontend/style.css` | Оформление и цвета статусов |
| `frontend/app.js` | Запросы к API и обновление карточек, карты и графика |
| `backend/main.py` | Сервер FastAPI: адреса API и фоновые задачи |
| `backend/sensors.py` | Датчики, симуляция и правила (норма / внимание / проблема) |
| `backend/open_meteo.py` | Загрузка настоящей погоды и воздуха |
| `backend/database.py` | Сохранение показаний в SQLite (`smart_city.db`) |
| `backend/requirements.txt` | Список библиотек Python |
