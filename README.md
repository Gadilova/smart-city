# 🏙️ Smart City Dashboard

Веб-панель мониторинга «умного города». Пока данные датчиков симулируются случайными числами.

## Модули
- 🚦 Трафик: машин в минуту, предупреждение о пробках
- 🌫️ Качество воздуха: индекс AQI
- 🅿️ Парковки: свободные места
- 💡 Освещение: автоматический ночной и дневной режим

## Как запустить
1. Открой папку в VS Code.
2. Установи расширение **Live Server**.
3. Правый клик по `index.html` → **Open with Live Server**.

Можно и без Live Server: просто открой `index.html` двойным щелчком.

## Структура
| Файл | Что делает |
|------|-----------|
| `index.html` | Разметка страницы: карточки и журнал |
| `style.css` | Оформление и цвета статусов |
| `app.js` | Симуляция датчиков, правила, обновление страницы |
